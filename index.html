01 / About

Software that moves.

I'm a software engineer working on mobility systems, helping a leading company in the sector modernize the services people rely on to get around.

I learned the hands-on way. At 42 School I rebuilt the classics from scratch: a Unix shell, an HTTP server, a raycasting engine. At SEA:ME I took that to cars, building Team06's autonomous model car with lane segmentation, traffic-sign detection and a Qt instrument cluster.

My toolbox runs from C++, Java and Python to Linux and Red Hat, with Claude Code for AI-assisted engineering.

On the side I build BikefitSim, an open-source app that clones your bike fit from any bike to any other.
